## 1. 공통 레이아웃

### 1.1 Header (데스크톱)

```
┌──────────────────────────────────────────────────────────┐
│  [🔵 ohdevlogfolio]    [홈] [프로젝트] [블로그]   [🌙/☀]  │
└──────────────────────────────────────────────────────────┘
```

- 로고: `Code2` 아이콘 + 사이트명, 홈 링크
- 네비게이션: 현재 경로 강조 표시 (bg-accent)
- ThemeToggle: 라이트/다크 전환 버튼
- 스크롤 시 배경 blur 처리 (`backdrop-blur-sm`)

### 1.2 Header (모바일)

```
┌────────────────────────────────────┐
│  [🔵 ohdevlogfolio]    [🌙] [☰]   │
└────────────────────────────────────┘
   ↓ 햄버거 열림 시
┌────────────────────────────────────┐
│  [홈]                              │
│  [프로젝트]                         │
│  [블로그]                           │
└────────────────────────────────────┘
```

```
