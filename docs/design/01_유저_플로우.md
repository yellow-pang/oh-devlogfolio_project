## 1. 사용자 유형별 주요 시나리오

| 유형                 | 주요 목적                                    | 진입 경로             |
| -------------------- | -------------------------------------------- | --------------------- |
| 방문자 (채용 담당자) | 기술 스택과 프로젝트 포트폴리오 확인 후 연락 | 이력서 링크 → 홈      |
| 방문자 (개발자)      | 블로그 글 읽기, 학습 내용 참고               | 검색 엔진 → 블로그 글 |
| 방문자 (클라이언트)  | 프로젝트 포트폴리오 확인 후 의뢰             | 소셜 링크 → 홈        |
| 관리자 (본인)        | 포스트 및 프로젝트 작성/수정/삭제            | `/admin` 직접 접근    |

## 2. 방문자 플로우

### 2.1 포트폴리오 확인 플로우 (채용 담당자)

```
[랜딩: 홈 /]
    │
    ├─ Hero 섹션 확인 (이름, 직함, 소개)
    ├─ 기술 스택 섹션 확인
    ├─ 프로젝트 섹션 확인
    │       │
    │       ├─ [GitHub 링크 클릭] → 외부 GitHub 새 탭 열림
    │       └─ [배포 링크 클릭] → 외부 데모 사이트 새 탭 열림
    │
    ├─ [프로젝트 더 보기 클릭] → [/projects 페이지] (미구현)
    │       │
    │       ├─ 기술스택 필터 선택
    │       └─ 프로젝트 카드 상세 확인
    │
    └─ 연락처 섹션 확인
            │
            ├─ [GitHub 클릭] → 외부 GitHub 새 탭
            ├─ [이메일 클릭] → 메일 클라이언트 실행
            └─ [LinkedIn 클릭] → 외부 LinkedIn 새 탭
```

### 2.2 블로그 읽기 플로우 (개발자 방문자)

```
[블로그 목록: /blog]
    │
    ├─ 포스트 카드 목록 확인
    ├─ [검색 입력] → 실시간 필터링 (미구현)
    ├─ [태그 클릭] → 해당 태그 포스트 필터링 (미구현)
    │
    └─ [포스트 카드 클릭] → [블로그 상세: /blog/[slug]]
            │
            ├─ 썸네일 확인
            ├─ 제목, 작성일, 태그 확인
            ├─ Markdown 본문 읽기
            ├─ 코드 블록 복사
            ├─ [이전 글 클릭] → 이전 포스트 (미구현)
            ├─ [다음 글 클릭] → 다음 포스트 (미구현)
            └─ [블로그 목록 클릭] → /blog 복귀
```

### 2.3 홈에서 블로그로 연결 플로우

```
[홈 /]
    │
    └─ [최근 글 섹션] (미구현)
            │
            └─ [포스트 카드 클릭] → /blog/[slug]
```

## 3. 관리자 플로우

> **현재 상태:** `/admin` 인증 없이 접근 가능 (MVP 제약)
> **계획:** Firebase Auth 연동 후 미인증 시 로그인 페이지로 리다이렉트

### 3.1 Admin 인증 플로우 (계획)

```
[/admin 접근]
    │
    ├─ [인증된 경우] → [Admin 대시보드]
    └─ [미인증 경우] → [/admin/login]
            │
            ├─ Email / Password 입력
            ├─ [로그인 성공] → [Admin 대시보드]
            └─ [로그인 실패] → 오류 메시지 표시
```

### 3.2 포스트 관리 플로우

```
[Admin 대시보드: /admin]
    │
    └─ [포스트 관리 클릭] → [/admin/posts]
            │
            ├─ 포스트 목록 확인
            │
            ├─ [포스트 작성 버튼]
            │       │
            │       ├─ 제목, slug, 요약, 본문(Markdown), 태그, 공개 여부 입력
            │       ├─ [저장 클릭] → 목록 갱신
            │       └─ [취소 클릭] → 폼 닫기
            │
            ├─ [수정 버튼 클릭] (특정 포스트)
            │       │
            │       ├─ 기존 데이터 폼에 로드
            │       ├─ 수정 후 [저장 클릭] → 목록 갱신
            │       └─ [취소 클릭] → 폼 닫기
            │
            ├─ [공개/비공개 토글] → published 상태 즉시 전환
            │
            └─ [삭제 버튼 클릭]
                    │
                    ├─ [확인 Dialog 표시] (AlertDialog 교체 예정)
                    ├─ [확인 클릭] → 삭제 후 목록 갱신
                    └─ [취소 클릭] → 취소
```

### 3.3 프로젝트 관리 플로우

```
[Admin 대시보드: /admin]
    │
    └─ [프로젝트 관리 클릭] → [/admin/projects]
            │
            ├─ 프로젝트 목록 확인
            │
            ├─ [프로젝트 추가 버튼]
            │       │
            │       ├─ 제목, 설명, 기술스택, GitHub URL, 배포 URL, featured 여부, 순서 입력
            │       ├─ [저장 클릭] → 목록 갱신
            │       └─ [취소 클릭] → 폼 닫기
            │
            ├─ [수정 버튼] (특정 프로젝트)
            │       └─ (포스트 수정과 동일 플로우)
            │
            └─ [삭제 버튼]
                    └─ (포스트 삭제와 동일 플로우)
```

## 4. 네비게이션 구조

```
ohdevlogfolio
│
├─ / (홈)
│   ├─ #hero
│   ├─ #projects
│   ├─ #skills
│   └─ #contact
│
├─ /blog (블로그 목록)
│   └─ /blog/[slug] (포스트 상세)
│
├─ /projects (프로젝트 목록) ← 미구현
│
└─ /admin (관리자)
    ├─ /admin/posts (포스트 관리)
    └─ /admin/projects (프로젝트 관리)
```

## 5. 에러/예외 플로우

| 상황                             | 처리 방식                                            |
| -------------------------------- | ---------------------------------------------------- |
| 존재하지 않는 slug로 블로그 접근 | `notFound()` → Next.js 404 페이지                    |
| 비공개 포스트 직접 URL 접근      | `notFound()` 처리                                    |
| Firestore 데이터 로드 실패       | 서비스 레이어에서 throw, 호출부에서 error state 표시 |
| Admin 미인증 접근 (계획)         | `/admin/login`으로 리다이렉트                        |
