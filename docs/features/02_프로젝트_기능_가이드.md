# 프로젝트 기능 가이드

> 이 문서는 ohdevlogfolio의 프로젝트 포트폴리오 기능을 설명합니다.  
> 홈 페이지의 프로젝트 섹션과, 별도의 `/projects` 전용 페이지 두 곳을 다룹니다.

---

## 1. 프로젝트 기능이란?

개발자가 진행한 프로젝트들을 카드 형태로 보여주는 포트폴리오 핵심 기능입니다.

- **홈 페이지**: 전체 프로젝트 목록을 한눈에 볼 수 있는 간략한 섹션
- **/projects 전용 페이지**: 기술스택으로 필터링할 수 있는 전체 프로젝트 목록

---

## 2. 페이지 구조

```
/           → 홈 페이지의 #projects 섹션 (ProjectList)
/projects   → 전용 프로젝트 목록 페이지 (필터 기능 포함)
```

---

## 3. 전체 데이터 흐름

```
사용자 브라우저
    │
    │  /projects 접속
    ▼
app/projects/page.tsx  (Server Component)
    │
    │  getAllProjects() 호출
    ▼
lib/services/projects.ts
    │
    │  현재: mockProjects 배열 반환
    │  (Firebase 연결 후: Firestore에서 읽어옴)
    ▼
ProjectFilter.tsx  (Client Component)
    │
    ├── 선택된 기술스택 상태 (useState)
    │
    │  projects.filter(...)로 화면에 표시할 프로젝트 결정
    ▼
ProjectCard.tsx × N개  → 화면에 카드 렌더링
```

## 4. 프로젝트 전용 페이지 (`/projects`)

### 4.1 구성 파일

| 파일                                         | 역할                                                   | 종류             |
| -------------------------------------------- | ------------------------------------------------------ | ---------------- |
| `src/app/projects/page.tsx`                  | 서버에서 프로젝트 데이터를 가져와 ProjectFilter에 넘김 | Server Component |
| `src/components/portfolio/ProjectFilter.tsx` | 기술스택 필터 UI와 ProjectCard 렌더링                  | Client Component |
| `src/components/portfolio/ProjectCard.tsx`   | 개별 프로젝트 카드                                     | Client Component |

### 4.2 기술스택 필터 기능

각 프로젝트는 사용된 기술스택 목록(`techStack`)을 가지고 있습니다.  
예: `["React", "TypeScript", "Firebase"]`

필터 버튼을 클릭하면 해당 기술을 사용한 프로젝트만 표시됩니다.

```
[All] [React] [TypeScript] [Next.js] [Firebase] ...
  ↑ 버튼은 전체 프로젝트의 techStack에서 자동으로 추출됨

"React" 클릭
    │
    ▼
selectedTech = "React"
    │
    ▼
projects.filter(project => project.techStack.includes("React"))
    │
    ▼
React를 사용한 프로젝트만 표시
결과 수 표시: "React 프로젝트 N개"
```

### 4.3 화면 레이아웃

```
┌─────────────────────────────────────────────┐
│  프로젝트                                     │
│  N개의 프로젝트                               │
├─────────────────────────────────────────────┤
│  [All] [React] [TypeScript] [Next.js] ...   │
│        ← 기술스택 필터 버튼                   │
├─────────────────────────────────────────────┤
│  ┌────────────┐  ┌────────────┐             │
│  │ ProjectCard│  │ ProjectCard│  ...        │
│  └────────────┘  └────────────┘             │
└─────────────────────────────────────────────┘
```

## 5. 홈 페이지 프로젝트 섹션

홈 페이지(`/`)에도 프로젝트 섹션이 있습니다.  
`ProjectList` 컴포넌트를 사용하며, `id="projects"` 앵커가 있어  
헤더 네비게이션의 "프로젝트" 링크를 클릭하면 이 섹션으로 스크롤됩니다.

> 헤더 네비게이션의 "프로젝트" 메뉴는 `/projects` 전용 페이지로 연결됩니다.  
> 홈의 섹션은 직접 스크롤하거나 앵커 링크(`/#projects`)로만 접근합니다.

---

## 6. ProjectCard 컴포넌트

각 프로젝트를 카드 형태로 표시합니다.

```
┌────────────────────────────────────────────┐
│  [썸네일 이미지]                   [★ 대표] │ ← featured 뱃지
├────────────────────────────────────────────┤
│  프로젝트 제목                              │
│  한 줄 소개 텍스트                          │
│                                            │
│  [React] [TypeScript] [Firebase]  ← techStack 뱃지
│                                            │
│  [GitHub 🔗]  [Live Demo 🔗]               │
└────────────────────────────────────────────┘
```

- **썸네일**: `thumbnailUrl` 필드의 이미지 URL 사용
- **★ 대표**: `featured: true`인 프로젝트에 표시
- **hover 효과**: 마우스를 올리면 카드가 살짝 올라오는 애니메이션 (`framer-motion`)
- **GitHub 버튼**: `githubUrl`이 있을 때만 표시
- **Live Demo 버튼**: `liveUrl`이 있을 때만 표시

## 7. 프로젝트 데이터 구조 (Project 타입)

```typescript
interface Project {
  id: string; // 고유 식별자
  title: string; // 프로젝트 이름
  description: string; // 짧은 한 줄 소개
  longDescription?: string; // 상세 설명 (선택 사항)
  thumbnailUrl: string; // 썸네일 이미지 URL
  tags: string[]; // 태그 (예: ["포트폴리오", "개인 프로젝트"])
  techStack: string[]; // 기술스택 (예: ["React", "TypeScript", "Firebase"])
  githubUrl?: string; // GitHub 저장소 링크 (선택 사항)
  liveUrl?: string; // 배포된 사이트 링크 (선택 사항)
  featured: boolean; // true = 대표 프로젝트로 강조 표시
  order: number; // 표시 순서 (숫자가 낮을수록 먼저 표시)
  createdAt: string; // 등록일
  updatedAt: string; // 수정일
}
```

> **tags vs techStack 차이:**
>
> - `tags`: 프로젝트 성격을 나타내는 키워드 (예: "포트폴리오", "팀 프로젝트")
> - `techStack`: 실제 사용한 기술 (예: "React", "Node.js") — 필터에 사용됨

## 8. 유저 플로우 (User Flow)

```
[홈 페이지 방문]
        │
    ┌───┴───────────────────────────────┐
    │                                   │
    │  헤더 "프로젝트" 클릭              │  홈에서 스크롤하여 프로젝트 섹션 도달
    ▼                                   ▼
[/projects 전용 페이지]          [홈 #projects 섹션]
        │
        │  기술스택 필터 버튼 클릭
        ▼
[필터링된 프로젝트 목록 표시]
        │
    ┌───┴───────────────────┐
    │                       │
    ▼                       ▼
[GitHub 링크 클릭]    [Live Demo 클릭]
[GitHub 새 탭 열림]   [배포 사이트 새 탭 열림]
```
