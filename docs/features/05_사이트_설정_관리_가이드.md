# feat/admin-site-settings 브랜치 작업 기록

## 브랜치 목적

배포 후에도 메인 페이지의 핵심 콘텐츠(이름, 직함, 소개, 기술 스택, 연락처 링크)를 Admin 패널에서 직접 수정할 수 있도록 **사이트 설정 관리 기능**을 추가한다.

---

## 수정 범위 요약

| 구분           | 내용                                                                    |
| -------------- | ----------------------------------------------------------------------- |
| 편집 가능 항목 | Hero 섹션 (인삿말, 이름, 직함, 소개), 기술 스택 그룹, 연락처 링크       |
| 데이터 저장소  | Firestore `siteSettings/main` 단일 도큐먼트                             |
| 편집 경로      | `/admin/settings`                                                       |
| 폴백 동작      | Firestore에 데이터 없으면 `defaultSiteSettings` (기존 하드코딩 값) 사용 |

---

## 데이터 구조 (Firestore)

**컬렉션**: `siteSettings`  
**도큐먼트 ID**: `main`

```json
{
  "hero": {
    "greeting": "Hello, World! 👋",
    "name": "Oh",
    "title": "Frontend Developer",
    "bio": "React · Next.js · TypeScript 를 좋아하는 프론트엔드 개발자입니다."
  },
  "skills": [
    {
      "category": "Frontend",
      "items": ["React", "Next.js", "TypeScript", "Tailwind CSS", "HTML/CSS"]
    }
  ],
  "contact": {
    "email": "contact@example.com",
    "github": "https://github.com/username",
    "linkedin": "https://linkedin.com/in/username"
  }
}
```

## Admin 사이트 설정 페이지 사용법

1. `/admin/login`에서 관리자 계정으로 로그인
2. 좌측 사이드바 하단 **"사이트 설정"** 클릭
3. 원하는 항목 수정:
   - **Hero 섹션**: 인삿말, 이름, 직함, 소개글
   - **기술 스택**: 카테고리 추가/삭제, 기술 항목은 쉼표(,)로 구분 입력
   - **연락처 링크**: 이메일 주소, GitHub URL, LinkedIn URL
4. 상단 또는 하단 **"저장"** 버튼 클릭
5. 메인 페이지(`/`) 새로고침 시 변경사항 즉시 반영

---

## 폴백(Fallback) 동작

Firestore에 `siteSettings/main` 도큐먼트가 없을 경우 `defaultSiteSettings` 값이 자동으로 사용된다. 최초 저장 시 Firestore에 도큐먼트가 생성된다.

---

## Firestore 보안 규칙 권장사항

`siteSettings` 컬렉션은 읽기는 누구나 가능하지만, **쓰기는 인증된 관리자만** 허용해야 한다.

```
match /siteSettings/{docId} {
  allow read: if true;
  allow write: if request.auth != null;
}
```
