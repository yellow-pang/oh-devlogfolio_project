# 카테고리 시스템 가이드

> 이 문서는 ohdevlogfolio의 카테고리 기능 구조를 설명합니다.  
> 카테고리가 어떻게 관리되고, 블로그 글과 어떻게 연결되는지를 다룹니다.

---

## 1. 카테고리란?

카테고리는 블로그 글을 **주제별로 분류하는 기준**입니다.  
예를 들어 "알고리즘 풀이"를 쓰면 `알고리즘` 카테고리, "React 공부 기록"을 쓰면 `개발일지` 카테고리로 분류합니다.

| 기본 제공 카테고리 | 설명                           |
| ------------------ | ------------------------------ |
| 개발일지           | 개발 과정 기록, 학습 일지      |
| 알고리즘           | 알고리즘 문제 풀이             |
| 언어/도구          | 언어·프레임워크·도구 학습 내용 |
| 개념정리           | CS 개념, 이론 정리             |
| 회고               | 프로젝트·학습 회고             |

## 2. 카테고리 데이터 구조

```typescript
// src/types/category.ts
interface Category {
  id: string; // 고유 식별자
  name: string; // 카테고리 이름 (예: "개발일지")
  createdAt: string; // 생성일 (ISO 8601 형식)
}

// 폼에서 사용하는 데이터 타입
type CategoryFormData = Pick<Category, "name">;
// ↑ Category에서 "name" 필드만 골라낸 것 (입력 폼은 이름만 필요)
```

## 3. 카테고리 시스템 전체 구조

```
데이터 레이어
    lib/mock/categories.ts  ← 현재: 하드코딩된 기본 카테고리 5개
    lib/services/categories.ts  ← CRUD 함수 (Firebase 연결 준비됨)
        │
        ▼
상태 관리 레이어
    hooks/useCategories.ts  ← 컴포넌트에서 사용하는 React 훅
        │
        ▼
UI 레이어
    app/admin/categories/page.tsx  ← 카테고리 관리 페이지
    components/admin/PostForm.tsx   ← 포스트 폼의 카테고리 드롭다운
```

## 4. 서비스 함수 (`lib/services/categories.ts`)

카테고리 데이터를 읽고 쓰는 함수들입니다.

| 함수                       | 역할                    |
| -------------------------- | ----------------------- |
| `getAllCategories()`       | 전체 카테고리 목록 반환 |
| `createCategory(data)`     | 새 카테고리 추가        |
| `updateCategory(id, data)` | 카테고리 이름 수정      |
| `deleteCategory(id)`       | 카테고리 삭제           |

현재는 Mock 데이터를 사용하며, Firebase 연결 시 Firestore 코드로 교체합니다.

---

## 5. useCategories 훅

컴포넌트에서 카테고리를 쉽게 사용하기 위한 커스텀 훅입니다.

```typescript
const {
  categories,
  loading,
  error,
  addCategory,
  editCategory,
  removeCategory,
} = useCategories();
```

| 반환값                   | 타입             | 설명                    |
| ------------------------ | ---------------- | ----------------------- |
| `categories`             | `Category[]`     | 현재 카테고리 목록      |
| `loading`                | `boolean`        | 데이터 불러오는 중 여부 |
| `error`                  | `string \| null` | 에러 메시지             |
| `addCategory(name)`      | 함수             | 새 카테고리 추가        |
| `editCategory(id, name)` | 함수             | 카테고리 이름 수정      |
| `removeCategory(id)`     | 함수             | 카테고리 삭제           |

## 6. 카테고리와 블로그 글의 연결

`Post` 타입에 `category?: string` 필드가 있습니다.  
Admin에서 글을 작성할 때 카테고리를 선택하면, 그 카테고리 이름이 `category` 필드에 저장됩니다.

```
카테고리 관리에서 "개발일지" 등록
    │
    ▼
PostForm 카테고리 드롭다운에 "개발일지" 표시
    │
    │  "개발일지" 선택 후 포스트 저장
    ▼
post.category = "개발일지"
```

> **`?` (옵셔널) 이유:**  
> 기존에 카테고리 없이 작성된 글도 오류 없이 표시되어야 하기 때문입니다.  
> 카테고리가 없는 글은 `category` 값이 `undefined`이며, 정상적으로 동작합니다.

## 7. Firebase 연결 시 교체 방법

```typescript
// 현재 (Mock)
export async function getAllCategories(): Promise<Category[]> {
  return mockCategories;
}

// Firestore 연결 후
export async function getAllCategories(): Promise<Category[]> {
  const snapshot = await getDocs(
    query(collection(db, "categories"), orderBy("createdAt", "asc")),
  );
  return snapshot.docs.map(
    (doc) => ({ id: doc.id, ...doc.data() }) as Category,
  );
}
```

각 CRUD 함수를 같은 방식으로 교체하면 됩니다.
