## 1. 문서 목적

본 문서는 ohdevlogfolio의 기능 요구사항과 비기능 요구사항을 정의합니다.  
개발 순서와 우선순위를 기준으로 작성했으며, 구현 여부를 함께 표기합니다.

---

## 2. 시스템 범위

### 2.1 MVP 포함 범위

| 구분            | 포함 기능                                                   |
| --------------- | ----------------------------------------------------------- |
| 포트폴리오 홈   | Hero, 기술 스택, 프로젝트 목록, 연락처                      |
| 프로젝트 페이지 | 목록, 기술스택 필터, GitHub/배포 링크, featured 강조        |
| 블로그          | 포스트 목록, 검색/태그 필터, 상세 페이지(Markdown)          |
| 관리자          | CRUD 대시보드 (포스트·프로젝트), 공개/비공개 관리           |
| 공통            | 다크/라이트 모드 전환, 모바일 반응형, Firebase Hosting 배포 |

### 2.2 MVP 제외 범위

| 구분          | 제외 기능                                      |
| ------------- | ---------------------------------------------- |
| Admin 인증    | Firebase Auth 연동 (2차 구현)                  |
| 댓글          | Giscus 또는 Disqus 연동 (2차 구현)             |
| 이미지 업로드 | Firebase Storage 미사용 원칙                   |
| 알림/RSS      | 독자 기반 형성 후 추가 예정                    |
| 페이지네이션  | 데이터 증가 후 Firestore cursor 기반 추가 예정 |
| 조회수        | Firestore 트랜잭션 기반으로 2차 구현 예정      |

## 4. 비기능 요구사항

### 4.1 성능

| 항목          | 기준                                                            |
| ------------- | --------------------------------------------------------------- |
| 정적 배포     | `next build` 후 `out/` 정적 파일로 완전 생성                    |
| 초기 로드     | 포트폴리오 특성상 LCP 2.5초 이내 목표                           |
| 이미지 최적화 | `unoptimized: true` 설정이므로, 외부 이미지 크기 직접 관리 필요 |

### 4.2 보안

| 항목                | 기준                                                          |
| ------------------- | ------------------------------------------------------------- |
| Admin 접근 제어     | Firebase Auth 연동 후 미인증 접근 시 로그인 페이지 리다이렉트 |
| 환경변수            | Firebase 설정값은 `.env.local`에서만 관리, `.gitignore` 포함  |
| Firestore 보안 규칙 | 읽기: 공개, 쓰기: 인증된 사용자만 허용                        |

### 4.3 유지보수성

| 항목                       | 기준                                                  |
| -------------------------- | ----------------------------------------------------- |
| 서비스 레이어 분리         | UI 컴포넌트와 데이터 접근 로직 분리 (`lib/services/`) |
| Mock → Firestore 교체 용이 | 서비스 함수 인터페이스 유지, 내부 구현만 교체         |
| TypeScript 전체 적용       | `any` 타입 사용 금지, 엄격한 타입 검사                |

### 4.4 접근성

| 항목              | 기준                             |
| ----------------- | -------------------------------- |
| 키보드 네비게이션 | 주요 인터랙션 키보드로 접근 가능 |
| 색상 대비         | WCAG AA 수준 이상                |
| 스크린 리더       | 주요 버튼/아이콘 aria-label 적용 |
