## 2. 완료된 작업 상세

### 1단계 — 프로젝트 구조 및 기반

- Next.js App Router + TypeScript 프로젝트 세팅
- 필요 패키지 설치 (framer-motion, next-themes, firebase, shadcn/ui, react-markdown 등)
- `Post`, `Project` TypeScript 인터페이스 정의
- `lib/mock/posts.ts`, `lib/mock/projects.ts` mock 데이터 작성
- `lib/services/posts.ts`, `lib/services/projects.ts` 서비스 레이어 분리
- `lib/firebase/config.ts` Firebase 초기화 코드 (환경변수 기반)
- `config/site.ts` 사이트 설정 중앙화
- `next.config.ts`: `output: "export"`, `images: { unoptimized: true }`

### 2단계 — 공통 레이아웃

- `Header`: 로고, 데스크톱 네비게이션, 모바일 햄버거 메뉴, ThemeToggle
- `Footer`: 저작권, 소셜 링크 (GitHub, LinkedIn, Email)
- `ThemeToggle`: Sun/Moon 아이콘 전환, `next-themes` 연동
- `ThemeProvider`: 라이트 기본, 다크 모드 전환 지원

### 3단계 — Home 페이지

- `HeroSection`: 이름, 직함, 소개, CTA 버튼, 소셜 링크, framer-motion 등장 애니메이션
- `SkillSection`: 카테고리별 기술 스택 카드
- `ProjectList`: 프로젝트 카드 그리드 (Home의 `#projects` 섹션)
- `RecentPostsSection`: 홈에 최신 블로그 글 3개 노출
- `ContactSection`: GitHub, 이메일, 이력서 다운로드 링크

### 4단계 — Blog

- `/blog`: 공개된 포스트 카드 목록, **제목 검색 + 태그 클릭 필터**
- `/blog/[slug]`: Markdown 본문, 태그, 작성일, 썸네일, **이전/다음 글 네비게이션**
- `PostCard`: 썸네일, 제목, 요약, 태그, 작성일 표시
- `MarkdownContent`: `react-markdown` + `rehype-highlight` 코드 블낅
- `Post` 타입에 `category?: string` 업선적 필드 추가

### 6단계 (부분) — Admin

- `/admin`: 통계 카드 (프로젝트 수, 포스트 수), 빠른 링크
- `/admin/posts`: 포스트 목록, CRUD, **제목 검색 필터**, 공개/비공개 토글, **AlertDialog 삭제 확인**
- `/admin/projects`: 프로젝트 목록, CRUD, **검색 필터**, **featured 토글**, AlertDialog 삭제 확인
- `/admin/categories`: **카테고리 CRUD 관리 페이지 (신규)**
- `PostForm`: react-hook-form 기반, **수정 시 카테고리 Select 드롭다운**, **썸네일 URL 실시간 미리보기**
- `ProjectForm`: react-hook-form 기반, **썸네일 URL 실시간 미리보기**
- `usePosts`, `useProjects`, `useCategories`: 훅 기반 상태 관리

## 5. 기술 부채

| 항목                  | 설명                                               | 해결 방향                                           |
| --------------------- | -------------------------------------------------- | --------------------------------------------------- |
| Admin 인증 없음       | `/admin` 라우트 누구나 접근 가능                   | Firebase Auth 또는 미들웨어 기반 보호               |
| 이미지 미최적화       | `unoptimized: true`로 Next.js 이미지 최적화 비활성 | Firebase Hosting 제약 사항. 외부 CDN 사용 검토 가능 |
| mock 데이터 in-memory | 새로고침 시 Admin CRUD 결과 초기화                 | Firestore 연결 후 해결됨                            |
